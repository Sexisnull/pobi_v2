## 0. 总判断（TL;DR）

之前的猜测与实测有出入，先修正三点：

1. **核心扫描逻辑（ADaPT 递归 / 置信度反馈树 / Validator / Recon）在 `pobi_agent` 中是完整复刻**，并非"黑盒"或"薄壳"。`agents/components/` 的 `executor.py`、`planner.py`、`validation_strategies.py` 与原版同体积同结构。
2. **Python 沙箱两边都是 `simple-python-interpreter-sandbox`（WebAssembly/pyodide）**，原版主 `sandbox.py` 仍是 Docker（仅 shell 用），Python 走独立 WASM 组件。之前"pobi_v2 把 Python 挂 Docker"的判断是错的——那只是适配层 description 字符串措辞。
3. **真正存在的偏离只有一处实质 + 一处适配层 bug**：
   - 实质偏离：Web 层(RAG)没接上内核已有的 RAG（`deadend_runner` 用错 API 名 `create_session`，原版叫 `get_connector`，导致永远降级 `None`）。
   - 适配层简化：`max_turns=50` 硬编码替代了文章的"递归深度=2"，可能限制 ADaPT 深层分解。

## 2. 重点偏离详解

### 2.1 （实质）RAG 在 Web 路径失效 —— 适配层 API 名不匹配

`pobi_v2/engine/deadend_runner.py` 第 271 行：

```python
if hasattr(rag_manager, "create_session"):
    rag_connector = rag_manager.create_session(session_id=session_id)
```

而原版 `RagSessionManager` 的方法是 `get_connector(agent_id, embedding_session_id, target)`，**不存在 `create_session`**。因此 `hasattr` 恒为 False，RAG connector 永远 `None`，检索降级关闭。

- 影响：文章把 RAG 视为降低 context 成本、提升效率的核心设施；在 pobi_v2 的 Web 运行路径上它实际没生效。
- 性质：**不是内核偏离（内核 RAG 完整），是 Web 适配层没接对 API**。修复成本极低——把 `create_session` 换成 `get_connector` 并补参数即可。
- 旁证：`EmbedderClient` 初始化失败也会降级 `None`（第 298 行），进一步加剧检索缺失。

### 2.2 （简化）`max_turns=50` 替代递归深度

`deadend_runner.run_deadend_agent` 硬编码 `max_turns: int = 50`。文章强调 `max recursive depth = 2` 是 planner 把主任务分解的**层级深度**，约束的是 ADaPT 树的展开层数；而 `max_turns` 约束的是**总Agent回合/工具调用数**。两者不是同一维度：

- 若内核内部没有独立的递归深度上限，仅靠 `max_turns` 总回合封顶，深层多分支分解可能在回合耗尽前被截断。
- 建议：核对 `components/planner.py` / `executor.py` 内部是否另有 `max_depth` 参数；若无，需在适配层显式传入递归深度而非仅靠 `max_turns`。

## 5. 结论

**核心扫描逻辑与文章描述高度一致**：ADaPT 递归规划、置信度反馈树、Validator(flag+judge)、Playwright 畸形请求、Docker shell 沙箱、WASM python 沙箱、6 子 Agent 委派，均在 `pobi_agent` 中完整保留（同源演进，非重新实现）。

**唯一影响实战效果的真实差距是 RAG 在 Web 路径未接通**（适配层 API 名写错导致降级 None），以及 `max_turns` 硬编码可能限制深层分解。这两项都集中在 `pobi_v2/engine/deadend_runner.py` 适配层，**内核无差距**——与既有 `docs/差距分析_deadend-cli_vs_pobi_v2.md` 的结论互相印证。

建议优先修复 `deadend_runner` 的 RAG 接入（低成本、直接恢复文章强调的 context 效率），其次核对 ADaPT 递归深度约束。
