关键洞察：原架构已经是"进程分离"的（Deno CLI ↔ Python 守护）。你只需把 Deno 侧换成"浏览器 + 一个薄后端"，JSON-RPC 桥几乎可以原样复用——这正是作者分层设计的红利。
